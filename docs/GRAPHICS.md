# Rendering, Textures & Shader Notes

This document describes the current renderer, which requested graphics features
apply to a 2D Canvas game, and how to move to a native Vulkan renderer without
touching the simulation.

## Current pipeline

- 2D top-down, one `SurfaceView`, dedicated game thread.
- **Hardware Canvas** via `SurfaceHolder.lockHardwareCanvas()`.
- 60 Hz fixed simulation: `System.nanoTime()` accumulator, 1/60 s steps,
  sleep-based frame cap, delta-time `Game.update(dt)` and `Game.render(canvas)`.
- **Textures:** `assets/tileset.png` — a 1024×1024 power-of-two atlas with 12
  material types × 4 variants at 128×128. It is generated by
  `tools/gen_tileset.py` (numpy + Pillow) and can be replaced by a Kenney/itch
  tileset. Tiles are drawn into 32-world-unit cells with bilinear filtering and
  reused destination rects.
- **Lighting:** `GpuLighting.kt` uses `RuntimeShader` (AGSL, API 33+) for a
  single full-screen pass: ambient darkness, up to three soft circular light
  pools (player torch + two nearby campfires), warm tint and dithering.
  API < 33 falls back to the previous translucent overlay + glow sprite.
- **Animation:** `SpriteAnimation` slices a sheet into equal frames with a
  configurable duration and loop flag; `AnimationSet` maps IDLE/WALK/ATTACK.
  The campfire flame is an 8-frame generated sheet. Water cycles atlas variants
  over time to shimmer.
- Creatures remain antialiased vector art so they can face any direction and
  scale crisply.

## Requested features vs. this renderer

| Request | Applies directly? | Status / what it would take |
| --- | --- | --- |
| **Vulkan renderer** | No. Canvas gives no `VkSurfaceKHR`/command buffers. | HWUI may use Vulkan internally, but apps cannot select it. Explicit Vulkan requires an NDK renderer: swapchain, sprite batcher, text, JNI bridge. The simulation is already decoupled, so it can be swapped in behind `WorldRenderer`. |
| **AGDK Swappy** | No. Swappy injects frames into native GLES/Vulkan swapchains. | The fixed-step accumulator + sleep is the Canvas equivalent. With a native renderer, Swappy is the right pacer. |
| **RuntimeShader (AGSL)** | **Yes (API 33+).** | Implemented for night lighting with three dynamic lights and a legacy fallback. |
| **LOD meshes** | No meshes in 2D. | 2D equivalents implemented: viewport culling, off-screen entity skip, boss updates only within 90 tiles, despawn at 65 tiles, quality tiers. |
| **ASTC primary / ETC2 fallback** | Only for uploaded GPU-compressed textures. | The atlas is a 1024² PNG decoded to ARGB for Canvas. For a native renderer, compress the same atlas to ASTC 4×4/6×6 with ETC2 fallback. It is already power-of-two. |
| **Power-of-two textures** | Yes. | Atlas is 1024×1024; individual cells are 128×128. |

The renderer is intentionally split (`WorldRenderer`, `GpuLighting`,
`TileAtlas`, `CreatureRenderer`) so a native backend can replace drawing while
keeping `Game`, world generation, AI and saves unchanged.

## Performance notes

- APK ~2.4 MB; 1.2 MB is the texture atlas. Decoded bitmap memory ~4 MB.
- 128 px source tiles downscale to ~93 px on a 1080p landscape screen with
  bilinear filtering.
- Daytime on the Android 15 emulator (SwiftShader): ~52–57 FPS. Night with the
  AGSL pass: ~50 FPS. Hardware GPUs are substantially faster.
- World chunks are `ByteArray`s generated lazily and evicted past six chunks.
- No per-tile allocations; minimap bitmap and glow sprite are reused.
- Quality settings reduce particle counts and hide small details; particles can
  be disabled entirely.

## Importing external art

1. Prefer a pack with clear licensing (Kenney CC0, OpenGameArt CC-BY, itch.io
   per-pack licenses). Keep the license in `docs/third_party/`.
2. Pack needed tiles into a power-of-two atlas (1024×1024 or 2048×2048), with
   2 px transparent padding to avoid bleeding.
3. Replace the atlas in `app/src/main/assets/tileset.png` (same 8-column,
   128 px cell layout) or adjust `TileAtlas.ATLAS_CELL/ATLAS_COLUMNS`.
4. For animated characters, add a sheet and use `SpriteAnimation` +
   `AnimationSet`; `CreatureRenderer` can then draw frames instead of vectors.
5. For a native Vulkan path, compress the atlas to ASTC and keep an ETC2 copy.

Sources:

- Kenney — <https://kenney.nl/assets> (CC0)
- itch.io free assets — <https://itch.io/game-assets/free>

## Native upgrade path

1. NDK module creates `VkSurfaceKHR` from the existing `SurfaceView`.
2. Upload the atlas once; batch visible tiles into one vertex buffer.
3. Add Swappy (`swappyVk_initAndGetRefreshCycleDuration`, `SwappyVk_queuePresent`).
4. Run the AGSL lighting math as a Vulkan fragment shader (the uniforms and
   falloff are portable).
5. Ship ASTC + ETC2 assets, choose at startup by device capability.
